# 📊 DB Interview Prep: SQL & MongoDB (Zero to Hero) 🚀

> **Complete Database Interview Preparation Guide in Hinglish** for Beginners, Freshers, and Experienced Engineers.
> Live URL: [https://db-interview-prep.vercel.app](https://db-interview-prep.vercel.app)

---

## 🌟 Features

- 🟢 **SQL Basics (Zero Se Shuru):** Database, Tables, Primary Key, Foreign Key, Constraints, Data Types, INSERT, SELECT, WHERE, UPDATE, DELETE, ORDER BY, LIMIT.
- 🟡 **SQL Intermediate:** INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, SELF JOIN, Aggregate Functions, GROUP BY, HAVING, Subqueries, Indexes, Views, CASE WHEN.
- 🔴 **SQL Advanced:** Transactions & ACID properties, Normalization (1NF, 2NF, 3NF, BCNF), Window Functions (ROW_NUMBER, RANK, DENSE_RANK, LEAD, LAG, PARTITION BY), CTEs (WITH clause), Stored Procedures, Triggers, Query Optimization with EXPLAIN.
- 🟢 **MongoDB Basics:** NoSQL vs SQL, JSON/BSON, Collections, Documents, _id ObjectId, CRUD operations (insertOne, insertMany, find, updateOne, deleteMany), Query Operators.
- 🟡 **MongoDB Intermediate:** Aggregation Pipeline ($match, $group, $project, $sort, $unwind, $lookup), Indexing (Compound, Multikey, Covered Queries), Data Modeling (Embedded vs Referenced).
- 🔴 **MongoDB Advanced:** Replication & Replica Sets (Primary, Secondary, Arbiter, Failover, Read Preference, Write Concern), Sharding & Horizontal Scaling (mongos, Config Servers, Shard Key selection), Multi-document ACID Transactions, TTL Indexes, Capped Collections.
- ⚔️ **SQL vs MongoDB:** Side-by-side comparison matrix, terminology mapping, query cheatsheet, decision framework, and Polyglot Persistence.
- 🏢 **Company-Wise Interview Questions:** TCS, Infosys, Wipro, Accenture, Amazon, Google, Microsoft, Flipkart, and FinTech (Razorpay, Paytm) with actual solutions.
- 📝 **Last Minute Cheat Sheet & Practice Arena:** Rapid-fire definitions, 60-second cheatsheets, and top 10 LeetCode / company interview coding problems with working queries.

## 🚀 Running Locally

\`\`\`bash
# 1. Clone the repository
git clone https://github.com/roshanraj9136/db-interview-prep.git
cd db-interview-prep

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) in your browser.
